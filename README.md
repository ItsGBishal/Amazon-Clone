# 🛒 Amazon Clone

## 📌 Project Overview

**Amazon Clone** is a responsive, full-featured e-commerce web application designed to replicate the core shopping experience of Amazon. Built with modern vanilla JavaScript (ES6+), semantic HTML5, and modular CSS3, the project provides an interactive online shopping workflow without relying on external frontend frameworks.

### Key Highlights:
- **Product Catalog**: Dynamic rendering of products loaded asynchronously from a backend API, complete with star ratings, pricing, quantity selection, and real-time cart badge updates.
- **Cart & Checkout**: Full cart management featuring item updates, item removal, multiple shipping/delivery options, and automated calculations for items subtotal, shipping fees, estimated tax, and order totals.
- **Orders & Tracking**: Dedicated order history and interactive package tracking timeline (Preparing → Shipped → Delivered).
- **State Persistence**: Client-side state retention using the browser `localStorage` API across page reloads and navigation.
- **Modular & OOP Design**: Built with clean ES6 modules, reusable utilities, and Object-Oriented Programming (classes, inheritance, polymorphism, and private class fields `#`).
- **Automated Testing**: Integrated unit tests and DOM integration tests using the Jasmine testing framework.
